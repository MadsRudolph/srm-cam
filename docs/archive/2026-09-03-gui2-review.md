## Not fixed — needs the machine idle (firmware)

`hardware/srm20_spi_probe/srm20_spi_probe.ino`, verified by reading, never run:

- **STOP does not lift.** `abortLift()` retracts with `jumpTo` → `waitForMotorStop`, whose `checkAbort()` sees the still-latched `gAbort` and cancels the retract on its first iteration. Motion and spindle do stop. Every UI string that said "lifts" now says to raise the bit with Page Up.
- **After STOP, `J` (click-to-jog) and `Y` (view position) silently do nothing** until an `N` move clears the hold. Fix: `clearHold()` in the `J`/`L`/`Y` handlers.
- **Fiducial surface reference can plunge 6 mm** into bare laminate: the first `P` after `D` has no reference, so the floor is `safeZ − PROBE_MAX_DROP_UM`. Pick a reference direction with copper under it, or send a shallow `Z` first.

Flash needs the machine idle; the baseline hex is in the scratch `fw-baseline/`.

## gui1 features still not in gui2

Ranked by what matters at the machine. Everything else in gui1 has an
equivalent (see the audit tables in the session log).

1. Pause / Resume (VPanel hold) — nothing in gui2 can hold a move.
2. Probe resume — a grid stopped at point 18 of 25 starts over.
3. Drift re-touch every N points and `flag_outliers` / refinement rows.
4. Dowel scheme controls: fresh vs grid, edge pair / flip axis, pitch, clearances, "cut dowels only".
5. Manual fiducial placement (drag pins on the canvas).
6. Align overlay to the bit (recover when G54 is not where the design is).
7. Exact screw-head-vs-toolpath sweep (gui2 checks lift, count, spread only).
8. V-bit fields (`tool_type`, tip, angle, target width) editable in the form.
9. Feed test card export + photo scoring; tool-wear ledger; detect uncut copper from a photo; simulate an existing .nc; export image + board summary.
10. Photo: choose anchor holes; opacity/dim sliders. Arrow-key XY jog. Help ▸ user guide (F1). Update check. KiCad plugin install.

Blocking deletion of `gerber2rml/gui/`: `engine/toolwear.py` imports
`gui.workspace`; four engine tests borrow gui1 windows
(`test_bedfixture.py`, `test_kicadplugin.py`, `test_machinetest.py`,
`test_photoshare.py`/`test_photorelay.py`); the engine modules in item 9
have no other caller.

## Test-suite note

`tests/test_window.py::test_stylesheet_parses_without_warning` takes 90 s+ in a
full run: it sets gui1's application stylesheet while ~90 gui2 windows from
earlier tests are still alive (their zero-delay timers hold them), and Qt
re-polishes every widget. Not a hang. Worth fixing by deleting windows at
fixture teardown.
