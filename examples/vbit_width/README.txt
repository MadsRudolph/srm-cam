V-bit width card - read with a multimeter (see vbit_width.py).
Rows top->bottom: 0.40 0.35 0.30 0.25 0.20 0.15 0.10 0.05 mm.
Narrowest row that still beeps = upper bound on the overcut:
0.05 beeps -> cut < 0.25 mm; 0.10 is the narrowest beeping ->
0.25-0.30 mm; and so on. Everything beeps and 0.05 looks fat ->
cut is undersized.
