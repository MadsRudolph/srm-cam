Bed leveling & probing

Isolation cuts are ~0.15 mm deep; FR-4 bows more than that. Probe the surface, and every cut follows it.

Needs the probe hardware

One-time Arduino install + flash: Hardware & firmware. Without it, Export probe files... gives you per-point programs for VPanel and you type the Z values in by hand.

Setup

  1. Wire Red clip (D7) → the copper board — the only clip; the tool grounds through the collet. Isolate the board from the bed (paper/tape under it). Spindle OFF.
  2. Origin G54 XY at machine origin, zero only Z. NC jobs obey G54 only.
  3. Connect Pick the COM port, Connect. Touch the red clip to the bit once — bit ○ should fill.

Probe

  1. Build grid Set nx × ny (3×3 to start), Build grid, check with Show grid.
  2. Park over point 1 Click-to-jog 2–3 mm above the first grid point — this becomes the datum.
  3. Probe over SPI Each point gets a two-stage verified touch; Z column fills live. STOP aborts instantly, even mid-descent.

drift chk (default: every 6 points) re-touches the reference and corrects thermal drift across the grid. Leave it on.

Check the mesh

One flaky touch poisons a height map. Press Mesh check — it flags:

  • Flaky points — no smooth surface can explain them → re-probe those.
  • Minimum depth — a cut depth that survives this mesh's uncertainty.
  • Coarse regions — with one-click Insert suggested row(s).

Apply & keep

  • Tick Apply bed leveling on export — every cutting Z warps to the surface.
  • Save CSV / Load CSV to keep the mesh; Save setup... includes it. Clear Z for a clean re-probe.

Top side (after the flip)

View = Top → Build grid → Clear Z → probe → Export top traces (leveled). The old mesh is invalid — the board sits on new terrain.
