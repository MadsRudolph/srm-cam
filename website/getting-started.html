Install & connect

Install SRM-CAM, plug in the mill and the laser, and learn the window. On Windows the mill also needs Roland's driver, once per PC. Then go on to From KiCad and Make a board.

Then, in SRM-CAM, Help › Add the SRM-CAM buttons to KiCad… (it also offers this a moment after it first opens). The buttons are on From KiCad.

Connect the machines

Three USB cables, on Windows, Linux and macOS alike. The mill has two: the black one is the Arduino fitted inside it (position, jog, probing, STOP), the white one is the mill's own (SRM-CAM sends the jobs over it). The run uses both. The laser has one.

  • The mill's link: press Connect on the machine bar at the bottom of the window (or Machine › Connect / disconnect, Ctrl+L). More on Machine control.
  • The laser (xTool F1 Ultra) shows up as a USB network adapter. SRM-CAM talks to it directly: no driver, and no xTool Creative Space. The laser page says when it has an answer. More on The laser page.
  • No PC at the mill? Install SRM-CAM on your own laptop (Windows, Linux or macOS) and plug the cables in yourself. On Windows, Roland's driver too.

Windows only: Roland's driver

Before the mill's USB goes into a Windows PC

On Windows, SRM-CAM cannot talk to the SRM-20 until the Roland driver is installed: Windows needs it to see the mill at all. When the driver is installed, the mill shows up as a printer called Roland SRM-20, and SRM-CAM sends the job to that printer. Without it, Start stops with “The Roland SRM-20 printer is not installed on this PC”.

On Windows the driver is the only thing you must install besides SRM-CAM. Download it from Roland before you plug the mill into the PC. Roland's VPanel is optional: the run in SRM-CAM sends the job itself, in Novice and in Pro, and does not use it. See when you want VPanel.

Download

It is on Roland DG's official download page for the SRM-20 (the monoFab SRM-20). Open it on the Software tab:

downloadcenter.rolanddg.com/SRM-20

Roland asks you to accept its software licence before the download, so there is no file link to paste here: click through on Roland's page. You get a zip file. Roland's own step-by-step guide is the Roland DG startup page for the SRM-20, and the steps below follow it.

Install the driver

The order matters. Do not connect the mill's USB cable to the PC until step 8. Plugging it in early can make the driver impossible to install.

  1. Log on as an administratorIf an older driver for the SRM-20 is installed, uninstall it first (Roland says to do this before installing 2.12): run SETUP64.exe from the old driver's folder, click Uninstall, pick the machine, click Start and restart the PC.
  2. Unzip the driverUnzip the file you downloaded and open the folder it makes.
  3. Open the folder for your WindowsWIN10X64 for 64-bit Windows 11 and 10, WIN10X86 for 32-bit Windows 10. The wrong folder cannot install the driver.
  4. Run the setupDouble-click SETUP64.exe (64-bit) or SETUP.exe (32-bit). If Windows asks User Account Control, click Yes.
  5. Pick the modelClick Install, choose SRM-20 as the Model and USB as the port, and click Start.
  6. Follow the installerAccept the licence, click Install (once in the installer, once in the Windows security window), then Finish.
  7. Power the millPlug in the mill's power cable and AC adapter, close the front cover and press the power button. Wait until the green light stops flashing and stays lit: that is the start-up finished.
  8. Now connect the USB cableUse the USB cable that came with the mill (the white one), straight into the PC: no USB hub and no extension cable. Windows finishes installing the driver. Do not unplug it until that is done.
  9. Check itOpen Control Panel › View devices and printers. The SRM-20 must be listed under Printers. If it is not, or it shows as Unspecified, see Troubleshooting.

VPanel (optional)

SRM-CAM does not need VPanel to cut a board: with the driver installed, the automatic run sends the job to the mill itself. Install VPanel only if you want one of these:

  • Pro, by hand: you export the files and play them from VPanel, as in Milling a board by hand.
  • The mill's own settings: the command set must be NC Code and the G54 X/Y origin must be machine 0, 0. They are stored in the mill, so a mill that is already set up needs nothing. If a run stops and names one of them, VPanel is where you change it on Windows.
  1. Unzip and runUnzip the VPanel file, double-click setup.exe in the folder, and follow the installer.
  2. Start it in the right orderClose the mill's front cover, switch the mill on and wait for the light to stay lit, then open Start › VPanel for SRM-20. If VPanel was opened with the mill off, switch the mill on and click Retry.
  3. Set it upIn VPanel, Setup › Command Set must be NC Code and the G54 X/Y origin must be machine 0, 0. The run stops before it cuts if either is wrong; see Troubleshooting.
On Linux and macOS

No driver and no VPanel. On Linux, plug in both USB cables, then use Machine › Set up USB access… once; it asks for your password. On macOS, Machine › Set up the mill on this Mac… once. On both, SRM-CAM sets the mill's Command Set to NC Code itself before a run, and Machine › The mill's settings… has the rest.

Staying current

The app checks GitHub for a newer release a moment after it opens and says so once, with the download link. Help › Check for updates… asks any time. It never installs anything by itself: you download the new file and install it the same way as the first time.

The first interface is still shipped: SRM-CAM --original from an install, python -m gerber2rml.gui from source. Same engine, same files.

The window

A header, the rail on the left, the bed in the middle, the page of the selected row on the right, and the machine bar at the bottom.

On the bed, drag the board, or tap the arrow keys to nudge it 0.1 mm (Shift 1 mm, Ctrl 0.01 mm). Scroll to zoom, right-drag to pan. As cut is the frame the machine works in; X-ray is for checking that the two faces of a two-sided board line up.

The rail

Which rows the rail has depends on the board's method, the tier, and the layers its folder has. A row that runs on a machine carries a MILL or LASER tag; a laser row opens the laser page beside the rail. At the foot: Save the files… in Novice, Export for VPanel… in Pro.

Novice & Pro

Two tiers. Click the tier chip at the top right of the window to switch, or use View › Novice controls / Pro controls. Novice is the default: the rail has only what the run needs (Make a board). Pro runs the same run and has everything else too. It is the same program and the same plan, and exported files are identical in both.

Help › What Novice and Pro differ by… lists it in the app. A lab that wants the profile fixed sets SRM_CAM_MODE to novice or pro in the environment or the shortcut.

By hand in VPanel (Pro)? Help › The machine, in five minutes has the lessons for that: see Milling a board by hand.

Setups

File › Save the setup… (Ctrl+S) writes one .srmcam file with everything: the boards and where they sit, the tool, the copper sheet, the screws, the height maps of both faces, the measured flip. File › Load a setup… brings it back. A setup written by the first interface loads too.

Save after probing

A probed height map is minutes of machine time. Save the setup right after probing; the map is in it.
