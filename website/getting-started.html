Getting started

Install SRM-CAM, learn the four regions of the window and the two tiers, and get the right files out of KiCad. Then go on to Milling a board.

Install

PlatformGet itNotes
WindowsSRM-CAM-Setup.exeNo Python needed. Start-menu entry, Documents\SRM-CAM\ workspace. Install a new version over the old one; setups and profiles survive.
LinuxSRM-CAM-x86_64.AppImage from the latest releasechmod +x, run. No install, no root; it carries its own Qt. The machine link is Windows-only: prepare and export on Linux, send the files from VPanel on a Windows PC, and carry a probed height map over as a CSV.
From sourcepip install -e ".[gui]" then python -m gerber2rmlAfter a git pull, python -m gerber2rml.doctor installs anything new.

No PC at the mill?

The lab's CNC PC has SRM-CAM and VPanel on it. If it isn't free, install both on your own Windows laptop (the link and VPanel are Windows-only) and plug in the two USB cables yourself.

Staying current

The app checks GitHub for a newer release a moment after it opens and says so once, with the download link. Help › Check for updates… asks any time. It never installs anything by itself: you download the new file and install it the same way as the first time.

The first interface is still shipped: SRM-CAM --original from an install, python -m gerber2rml.gui from source. Same engine, same files.

The window

Four regions that never move, and a header. Tap one to see what it is for; tap a step on the rail and the stage draws its toolpath, as the app does.

  • The rail (left) is the run plan: the same order, and the same files, that the export writes. Numbered steps are files you send; the rows between them (fit the bit and set the Z origin, flip the board) are things you do by hand. Click any step at any time; nothing is locked. A finding that matters stays on the red banner until it is fixed. Export the job is at the bottom.
  • The stage (middle) is the bed in machine coordinates: the copper sheet, the board, the toolpaths of the selected step, the spoilboard's screw grid. Drag the board, or tap the arrow keys to nudge it 0.1 mm (Shift 1 mm, Ctrl 0.01 mm). Scroll to zoom, right-drag to pan, Fit to frame the work. Bed — as cut is the only frame the machine understands; Design X-ray is for checking that the two faces of a double-sided board register.
  • The inspector (right) shows the selected step: the setup page, the checks, or a step's parameters, estimate and file.
  • The machine bar (bottom) is always there: Connect and the port, the position readout (always machine coordinates), Z jog, Probe Z, Zero Z, Spindle, Click to jog, and STOP. Esc stops the machine from anywhere, including with a dialog open.

Essential & Full

Two tiers, on the Interface menu. Essential is the whole single-sided job, including bed levelling, and it is the default. Full adds the rest. Essential is a strict subset: the same controls, the same handlers, and files that come out byte for byte identical.

Essential keepsFull adds
Bed levelling: the stop control is part of the window, so probing is safe to keepPer-operation cutting parameters: feeds, depths, offsets, stepover, V-bit geometry, and Cut gaps too narrow for the bit (in Essential the tool profile sets these)
The dry runDouble-sided boards: registration, the flip, top traces

Placing the job on the bedStreaming over the link (experimental), the machine test, saving your own tool profiles

Interface › What the two tiers differ by… lists it in the app. A lab that wants the tier fixed sets SRM_CAM_MODE to essential or full in the environment or the shortcut.

The machine, in five minutes

Help › The machine, in five minutes is the part that is true at every step: VPanel's three coordinate systems and why G54 is the one that matters; zero Z and leave X and Y alone; keep machine Z above −50 mm with the bit on the copper (−55 is the end of the travel); the probe's one wire, the red clip on the copper; STOP against Pause; and where the files go.

Files from KiCad

Before you route: clearance and the build area

Set the net class clearance to at least the width of the bit (Board Setup › Design Rules › Net Classes): a 0.8 mm endmill cannot enter a gap narrower than 0.8 mm. The app's checks list every gap that is too narrow, but it is quicker to fix before routing. KiCad › Set up the build-area plugin… in SRM-CAM adds a button to KiCad's PCB editor that draws the SRM-20's build area around your board and says whether it fits.

  1. Plot Gerbers File › Fabrication Outputs › Gerbers: at least B.Cu and Edge.Cuts (and F.Cu for double-sided), into one folder. If KiCad asks to refill the zones, say yes.
  2. Drill files Same dialog, Generate Drill Files…: Excellon, millimetres, into the same folder. KiCad writes the plated and unplated holes as two files; keep both.
  3. Open In SRM-CAM, File › Open Gerber folder… (Ctrl+O) picks up the layers and the drills and names the job after the KiCad project.
No KiCad handy?

Demo board on Set up the job › The board loads a bundled 40×30 mm coupon that exercises every operation.

Setups

File › Save the setup… (Ctrl+S) writes one .srmcam file with everything: the boards and where they sit, the tool, the copper sheet, the screws, the height maps of both faces, the measured flip. File › Load a setup… brings it back. A setup written by the first interface loads too.

Save after probing

A probed height map is minutes of machine time. Save the setup right after probing; the map is in it.
