Install & KiCad

First Roland's driver (required, once per PC), then SRM-CAM. Learn the four regions of the window and Novice and Pro, and get the right files out of KiCad. Then go on to Mill a board.

Required before first use: Roland's driver

SRM-CAM does not work on its own

SRM-CAM cannot talk to the SRM-20 until the Roland driver is installed. Windows needs it to see the mill at all. When the driver is installed, the mill shows up as a printer called Roland SRM-20, and SRM-CAM sends the job to that printer. Without it, Start stops with “The Roland SRM-20 printer is not installed on this PC”.

The driver is the only thing you must install. Download it from Roland before you plug the mill into the PC. Roland's VPanel is optional: the run in SRM-CAM sends the job itself, in Novice and in Pro, and does not use it. See when you want VPanel.

Download

It is on Roland DG's official download page for the SRM-20 (the monoFab SRM-20). Open it on the Software tab:

downloadcenter.rolanddg.com/SRM-20

Roland asks you to accept its software licence before the download, so there is no file link to paste here: click through on Roland's page. You get a zip file. Roland's own step-by-step guide is the Roland DG startup page for the SRM-20, and the steps below follow it.

Install the driver

The order matters. Do not connect the mill's USB cable to the PC until step 8. Plugging it in early can make the driver impossible to install.

  1. Log on as an administratorIf an older driver for the SRM-20 is installed, uninstall it first (Roland says to do this before installing 2.12): run SETUP64.exe from the old driver's folder, click Uninstall, pick the machine, click Start and restart the PC.
  2. Unzip the driverUnzip the file you downloaded and open the folder it makes.
  3. Open the folder for your WindowsWIN10X64 for 64-bit Windows 11 and 10, WIN10X86 for 32-bit Windows 10. The wrong folder cannot install the driver.
  4. Run the setupDouble-click SETUP64.exe (64-bit) or SETUP.exe (32-bit). If Windows asks User Account Control, click Yes.
  5. Pick the modelClick Install, choose SRM-20 as the Model and USB as the port, and click Start.
  6. Follow the installerAccept the licence, click Install (once in the installer, once in the Windows security window), then Finish.
  7. Power the millPlug in the mill's power cable and AC adapter, close the front cover and press the power button. Wait until the green light stops flashing and stays lit: that is the start-up finished.
  8. Now connect the USB cableUse the USB cable that came with the mill (the white one), straight into the PC: no USB hub and no extension cable. Windows finishes installing the driver. Do not unplug it until that is done.
  9. Check itOpen Control Panel › View devices and printers. The SRM-20 must be listed under Printers. If it is not, or it shows as Unspecified, see Troubleshooting.

VPanel (optional)

SRM-CAM does not need VPanel to cut a board: with the driver installed, the automatic run sends the job to the mill itself. Install VPanel only if you want one of these:

  • Pro, by hand: you export the files and play them from VPanel, as in Milling a board.
  • The mill's own settings: the command set must be NC Code and the G54 X/Y origin must be machine 0, 0. They are stored in the mill, so a mill that is already set up needs nothing. If a run stops and names one of them, VPanel is where you change it on Windows.
  1. Unzip and runUnzip the VPanel file, double-click setup.exe in the folder, and follow the installer.
  2. Start it in the right orderClose the mill's front cover, switch the mill on and wait for the light to stay lit, then open Start › VPanel for SRM-20. If VPanel was opened with the mill off, switch the mill on and click Retry.
  3. Set it upIn VPanel, Setup › Command Set must be NC Code and the G54 X/Y origin must be machine 0, 0. The run stops before it cuts if either is wrong; see Mill a board.
On Linux

No driver and no VPanel: the kernel already knows the mill. Plug in both USB cables (the mill's and the Arduino's), then use Machine › Set up USB access… once; it asks for your password. SRM-CAM sets the Command Set itself before a run.

No PC at the mill?

The lab's CNC PC has SRM-CAM and VPanel on it. If it isn't free, install both on your own Windows laptop (the link and VPanel are Windows-only) and plug in the two USB cables yourself.

Staying current

The app checks GitHub for a newer release a moment after it opens and says so once, with the download link. Help › Check for updates… asks any time. It never installs anything by itself: you download the new file and install it the same way as the first time.

The first interface is still shipped: SRM-CAM --original from an install, python -m gerber2rml.gui from source. Same engine, same files.

The window

Four regions that never move, and a header. Tap one to see what it is for; tap a step on the rail and the stage draws its toolpath, as the app does.

  • The header (top): the chip at the left says how the board is made (click it to choose another), CNC / Laser switches between the mill's page and the laser's, and the tier chip at the right switches Novice and Pro. The status chips (Mesh, Fit, Photo, Boxes) only show once they are lit.
  • The rail (left) is the plan, for both machines, in groups: On the mill (the run), One step at a time (Pro only, folded shut under the run: click it to open it; each mill step has Run this step on the mill, which finds the stock, probes and cuts that step alone), On the laser and When you need it. Rows that run on a machine carry a MILL or LASER tag; picking a laser row opens the laser page beside the rail. Click any row at any time; nothing is locked. A finding that matters stays on the red banner until it is fixed. At the foot of the rail: Export for VPanel… in Pro, Save the files… in Novice.
  • The stage (middle) is the bed in machine coordinates: the copper sheet, the board, the toolpaths of the selected step, the spoilboard's screw grid. Drag the board, or tap the arrow keys to nudge it 0.1 mm (Shift 1 mm, Ctrl 0.01 mm). Scroll to zoom, right-drag to pan.
  • The bed's toolbar (above the stage): Turn left, Turn right, Mirror, Centre (on the copper once it is set, otherwise on the bed), Undo (Ctrl+Z takes back any of them), Photo ▾, Bed — as cut / Design X-ray, Fit and Travel moves. Bed — as cut is the only frame the machine understands; Design X-ray is for checking that the two faces of a double-sided board register.
  • The inspector (right) shows the selected step: the setup page, the checks, or a step's parameters, estimate and file.
  • The machine bar (bottom) is always there: Connect and the port, the position readout (always machine coordinates), the jog pad, View, Probe Z, Pause, Click to jog, and STOP. Esc stops the machine from anywhere, including with a dialog open.

Novice & Pro

Two tiers. Click the tier chip at the top right of the window to switch, or use View › Novice controls / Pro controls. Novice is the default and is built around one thing: Mill a board. Pro runs the same run and has everything else too. It is the same program and the same plan, and exported files are identical in both.

Help › What Novice and Pro differ by… lists it in the app. A lab that wants the profile fixed sets SRM_CAM_MODE to novice or pro in the environment or the shortcut.

The machine, in five minutes

Help › The machine, in five minutes is the part that is true at every step: VPanel's three coordinate systems and why G54 is the one that matters; zero Z and leave X and Y alone; keep machine Z above −50 mm with the bit on the copper (−55 is the end of the travel); the probe's one wire, the red clip on the copper; STOP against Pause; and where the files go.

Files from KiCad

Before you route: the KiCad buttons

Help › Add the SRM-CAM buttons to KiCad… in SRM-CAM adds three buttons to KiCad's PCB editor:

  • Show SRM-20 build area draws the mill's build area around your board and says whether it fits.
  • Set design rules for SRM-CAM: choose how the board is made (flat mill, ball mill or fiber laser), and it sets the clearances and track widths for that. SRM-CAM reads the choice when it opens the board: see How it is made.
  • Send to SRM-CAM plots every layer SRM-CAM reads (copper, outline, mask, silkscreen and paste) with the drill files, checks the board against its method, and opens it in SRM-CAM. A board with no method set is checked against the one its own rules point to.

By hand: set the net class clearance to at least the width of the bit (Board Setup › Design Rules › Net Classes): a 0.8 mm endmill cannot enter a gap narrower than 0.8 mm. The app's checks list every gap that is too narrow for the method, but it is quicker to fix before routing.

  1. Plot Gerbers File › Fabrication Outputs › Gerbers: at least B.Cu and Edge.Cuts (and F.Cu for double-sided), into one folder. Add the mask, silkscreen and paste layers if the board will get solder mask, silkscreen or a stencil on the laser: each one adds a row to the rail. If KiCad asks to refill the zones, say yes. Send to SRM-CAM does all of this in one press.
  2. Drill files Same dialog, Generate Drill Files…: Excellon, millimetres, into the same folder. KiCad writes the plated and unplated holes as two files; keep both.
  3. Open In SRM-CAM, File › Open Gerber folder… (Ctrl+O) picks up the layers and the drills and names the job after the KiCad project.
No KiCad handy?

Demo board on Set up the job › The board loads a bundled 40×30 mm coupon that exercises every operation.

Setups

File › Save the setup… (Ctrl+S) writes one .srmcam file with everything: the boards and where they sit, the tool, the copper sheet, the screws, the height maps of both faces, the measured flip. File › Load a setup… brings it back. A setup written by the first interface loads too.

Save after probing

A probed height map is minutes of machine time. Save the setup right after probing; the map is in it.
