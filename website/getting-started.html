Getting started

Install the app, take the guided tour, and learn your way around the main window before touching real stock.

Install

Windows installer (recommended)

  1. Download the installer Grab the latest SRM-CAM-Setup-*.exe from the Releases page, or use the direct latest-installer link. No Python needed.
  2. Run it The installer creates a Start-menu entry (and optionally a desktop icon), plus your workspace folders under Documents\SRM-CAM\.
  3. Launch SRM-CAM A demo board loads on first run and the guided tour starts automatically.

From source

pip install -e ".[gui]"
python -m gerber2rml            # GUI
python -m gerber2rml.cli <gerber-folder> -o out -n <board>   # headless CLI

After a git pull, run python -m gerber2rml.doctor to install any new dependencies.

Upgrading

Installing a newer SRM-CAM-Setup over an existing install upgrades in place. Your sessions, presets, and probe CSVs live in your Documents and user folders, so nothing is lost. If you saved a setup mid-job, Load setup... restores it exactly after the update.

Your workspace folders

SRM-CAM keeps its working files in Documents\SRM-CAM\ — the file dialogs open there by default:

FolderWhat lives there
Documents\SRM-CAM\sessionsSaved setups (Save setup... / Load setup...) — the whole app state as a .json file, including the board, placement, all job settings, the probed height map, rework boxes, and the aligned photo.
Documents\SRM-CAM\exportsExported .nc / .rml job files and the run plan.
Documents\SRM-CAM\photosBoard photos for the photo overlay / rework detection.

The guided tour

On first launch the interactive tour walks you through the core workflow using the bundled demo board. You can replay it any time with the Guide button in the machine dock at the bottom of the window. Individual sections also have their own guide buttons (for example Guide: Bed leveling and Guide: Rework) that jump straight into that topic's mini-tour.

The main window

Left — the run-plan sidebar

The sidebar is the order of operations for a full job. Click any step to open its settings — nothing is locked; you can jump around freely:

  1. 1 · Setup board — load Gerbers, place on the bed, set stock, pick a preset, export.
  2. 2 · Bed leveling — probe a height map so cut depth follows the real surface.
  3. 3 · Registration — double-sided settings: dowels or fiducials.
  4. 4 · Drill through 8 · Top traces — the per-operation steps of the run plan.
  5. Rework — mark and re-cut spots that didn't cut through, with photo assistance.
  6. 3D viewer — toolpath simulation and the 3D bed height-map.

For a simple single-sided board you'll mostly live in 1 · Setup board, with optional visits to 2 · Bed leveling and Rework.

Right — the preview canvas

The 2D preview shows the bed, your placed board, and the toolpaths of the selected operation. Below it:

  • ◀ Hide panel — collapse the settings panel for a bigger preview.
  • Fit — zoom to fit everything.
  • The scrub slider plays the toolpath from 0–100% so you can see cut order.
  • A time estimate for the current operation.

The canvas is also interactive: drag the design to move it on the bed, use the ruler to measure, and — with the machine connected — click to jog the tool (more on that in Hardware & firmware).

Bottom — the machine dock

Always visible, in every step:

  • Connect + port picker — the serial link to the Arduino probe board. The label next to it is the live DRO: machine offline when disconnected, x=… y=… z=… when live.
  • bit ○ — the touch indicator: the circle fills when the bit is electrically touching the copper.
  • Probe Z, Zero Z on machine, Click to jog, Align overlay, Trail — machine tools covered in the relevant chapters.
  • STOP — the red abort button. Always enabled: it halts probing/jogging, lifts the bit to safe height, and disconnects. When in doubt, hit it.
  • The Run: row — live progress tracking with an ETA while VPanel plays a job (see Milling a board).

Status chips

The status bar shows small chips summarizing where your setup stands at a glance — board, placed, mesh, photo, boxes, machine, touch, fit and so on. They light up as each piece falls into place, so you can tell in one look whether the height map is loaded or the touch probe is wired before you commit to a cut.

Exporting files from KiCad

SRM-CAM reads a folder of standard KiCad plot output:

  1. Plot the Gerbers In KiCad: File → Fabrication Outputs → Gerbers. Include at least B.Cu and Edge.Cuts (plus F.Cu for double-sided boards).
  2. Generate the drill file In the same dialog, Generate Drill Files → Excellon format.
  3. Point SRM-CAM at the folder Everything goes in one folder; Load Gerber folder... picks up all layers and the drills automatically.
Try it without KiCad

A calibration coupon ships with the app — a 40×30 mm board that exercises every operation (isolation pairs, drill sizes, a registration grid, a roundness ring, a tabbed cut-out). Load examples/calibration as the Gerber folder and follow the tour with it.

Sessions: save your whole setup

Anything beyond a five-minute job is worth saving. Save setup... (in 1 · Setup board) writes the entire state to a session file: the loaded board, placement and rotation, all trace/drill/cutout parameters, double-sided configuration, the probed height map, rework boxes, and the aligned photo. Load setup... restores it exactly — including after an app update or a PC restart mid-job.

Save before you probe, save after you probe

A probed height map represents real machine time. Save the session right after probing so a crash or restart never costs you the mesh.
