Getting started

Install, take the tour, learn the window.

Install

  1. Download SRM-CAM-Setup.exe — no Python needed.
  2. Run the installer Creates the Start-menu entry and Documents\SRM-CAM\ workspace folders.
  3. Launch A demo board loads and the guided tour starts. Replay it anytime with Guide.

From source:

pip install -e ".[gui]"
python -m gerber2rml
Upgrading

Install the new setup over the old one. Sessions, presets, and probe CSVs survive.

The main window

  • Sidebar — the run plan: 1 · Setup board → 8 · Top traces, plus Rework and 3D viewer. Click any step, nothing is locked. Single-sided boards mostly live in step 1.
  • Preview — toolpaths on the bed. Drag to place the board, scrub the slider to see cut order, Fit to re-center. Click-to-jog when connected.
  • Machine dock — Connect + port, live DRO, bit ○ touch indicator, Probe Z, Click to jog, red STOP (always works), and the Run: progress row.
  • Status chips — board · placed · mesh · photo · boxes · machine · touch · fit light up as your setup completes.

Files from KiCad

  1. Plot Gerbers File → Fabrication Outputs → Gerbers — at least B.Cu + Edge.Cuts (+ F.Cu for double-sided).
  2. Drill files Same dialog → Generate Drill Files (Excellon). Everything in one folder.
  3. Load Load Gerber folder... picks up all layers + drills automatically.
No KiCad handy?

Load examples/calibration — a bundled 40×30 mm test board that exercises every operation.

Sessions

Save setup... stores everything — board, placement, all settings, height map, rework boxes, photo — in one file. Load setup... restores it exactly, even after an update.

Save after probing

A probed height map is real machine time. Save the session right after probing.
