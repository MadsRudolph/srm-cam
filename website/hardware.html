Hardware & firmware

An Arduino on the SRM-20's internal SPI bus = live DRO, electrical touch sensing, auto probing, click-to-jog, auto fiducial finding.

Optional — everything else works without it

This whole page is about one convenience: automatic probing. Traces, drilling, cut-out, double-sided registration, rework, simulation and every export run on a stock SRM-20 through VPanel with nothing fitted to the machine, and Novice mode hides the machine link entirely. Bed leveling still works too — measure the grid by hand and type the heights in.

Install (one-time)

  1. Fit the Arduino Behind the SRM-20's back panel, wired to the controller's SPI header. Full wiring: docs/2026-06-25-srm20-spi-and-bed-leveling.md in the repo.
  2. Flash hardware/srm20_spi_probe/srm20_spi_probe.ino (needs the bundled SRM20SPIRemote library). 115200 baud.
  3. Verify, then close the Serial Monitor You should see # SRM-20 grid prober v2 ready. The app can't open the port while the Serial Monitor holds it.
Old firmware?

If probing works but Auto fiducials or drift correction don't, reflash — one flash gets everything (v2).

Probe wiring (every session)

One clip: red (D7) → the copper board. The tool is already grounded through the collet/spindle to the machine frame. Bit touches copper → D7 pulled LOW = contact.

  • Isolate the board from the bed (paper/tape under it) — the only ground path must be the bit on copper.
  • Spindle OFF for all probing.
  • Test: touch the red clip to the bit — bit ○ fills.

How a touch is measured

  • Debounced — 3 consecutive LOW reads; stepper EMI can't fake a touch.
  • Two-stage verified — coarse 25 µm find, lift, fine 10 µm re-touch; must agree within 60 µm or the point retries → UNSTABLE.
  • Drift-corrected — periodic reference re-touch (drift chk) corrects warm-up drift.

Serial protocol (bench reference)

115200 baud, newline-terminated, microns. The app speaks it for you.

CmdMeaning
D / P id x y / BSet datum / probe point / re-touch reference (drift)
T / WTouch-off / touch-off + zero work-origin Z
H x yHole test: H 1 copper, H 0 hole
J x y / LJog (lifts first) / lift to safe Z
Q / G / VPosition+touch / work origin / version+features
C / M x y z sExperimental streaming: begin session / one move
!ABORT — always honoured

Errors: E <id> NOTOUCH | UNSTABLE | NODATUM | ABORT | RUNAWAY — meanings in Troubleshooting.

Streaming (experimental)

Stream (exp.) sends toolpaths move-by-move over SPI — no VPanel. Every session starts as a dry run (Z held 2 mm up, can't cut); a wet run needs the spindle started by hand + confirmation + speed calibrated on dry runs. For real jobs, use exported .nc through VPanel.
