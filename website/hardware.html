Hardware & firmware

A small Arduino wired to the SRM-20's internal SPI bus gives SRM-CAM a live machine link: a real DRO, electrical touch sensing, auto bed probing, click-to-jog, and the automatic fiducial finder.

What it unlocks

FeatureWhere it's used
Live DRO (true position readout)Machine dock — position, touch state, run tracking with ETA
Click-to-jogThe preview canvas becomes a remote control for the bed
Auto bed probingBed leveling: probe the whole grid unattended
Auto fiducial findingDouble-sided: the Auto button locates hole centers electrically
Rework depth probingRework: Probe boxes corrects each box's depth
Touch-off / Zero ZProbe Z and Zero Z on machine buttons

Installing the board (one-time)

  1. Fit the Arduino Open the SRM-20's back panel and install the Arduino, wired to the controller's internal SPI header. The full wiring walkthrough is in the repo: docs/2026-06-25-srm20-spi-and-bed-leveling.md.
  2. Flash the firmware Open hardware/srm20_spi_probe/srm20_spi_probe.ino in the Arduino IDE. It needs the bundled hardware/SRM20SPIRemote library (copy it into your Arduino libraries folder). Upload.
  3. Verify Open the Serial Monitor at 115200 baud — you should see # SRM-20 grid prober v2 ready. Then close the Serial Monitor: the app can't open the port while it's open.
Already installed, older firmware?

If probing works but Auto fiducial finding or drift correction doesn't, you're on firmware v1. One reflash of the current srm20_spi_probe.ino upgrades everything at once — verified touches, drift correction, Z zeroing, hole testing, and streaming.

Probe wiring (every session)

Touch sensing is a simple circuit: the copper board floats HIGH through the Arduino's pull-up, and the tool is already at ground — it grounds through the collet and spindle to the machine frame, which the Arduino shares. So there is exactly one clip to attach:

ClipGoes to
D7 (red / signal)the copper board (the workpiece)

The bit touching the copper pulls D7 LOW = contact. No clip on the tool — the ground path is the machine itself.

  • The board must be electrically isolated from the bed — put paper or tape underneath. The only path to ground must be the bit touching copper.
  • Spindle stays OFF for all probing.
  • Quick test: connect in the app, then touch the red clip against the bit or collet — the bit ○ indicator in the machine dock should fill.

Connecting from the app

In the machine dock: pick the Arduino's COM port, press Connect. The DRO label goes live and updates continuously. Connect again disconnects.

Machine dock tools

  • Probe Z — touch-off: descend from here until contact, stop at the surface.
  • Zero Z on machine — touch-off and write the origin Z at the copper surface. Caveat: this writes the origin VPanel displays (the User coordinate system). NC jobs obey G54, and whether G54 picks this up is machine-config dependent — verify VPanel's G54 Z once before trusting it for NC work.
  • Click to jog — click anywhere on the preview and the tool lifts ~5 mm, then travels there. Clicks snap to the nearest drill hole or dowel/fiducial pin when one is close; Ctrl+click jogs to the exact clicked point instead.
  • Align overlay — nudge the on-screen overlay to match reality: click the design point the bit is physically at, and the preview shifts to agree. Display-only; exports and job coordinates are untouched. Ctrl+click clears the trim.
  • Trail / Clear trail — draw the tool's path on the preview while a job runs.
  • STOP — the red button. Aborts any descent immediately, lifts to safe Z, halts. It is honoured between every probing step, so it can never keep stepping the bit into the work.

How a touch is measured

Firmware v2 treats every touch with suspicion, which is why the height maps are trustworthy:

  • Debounced contact — three consecutive LOW reads, 1 ms apart, so stepper EMI flashing the probe line can't fake a touch.
  • Two-stage verified touch — coarse contact at 25 µm steps, lift 150 µm, re-descend at 10 µm (the machine's native step). The two touches must agree within 60 µm or the point retries and then reports UNSTABLE rather than poisoning the grid.
  • Drift correction — the host periodically re-touches the reference point (the drift chk setting) and corrects the whole grid for warm-up drift and board settling.

Built-in safety limits

GuardValueWhat it prevents
Absolute drop floor6 mm below safe ZDescending forever if the wiring is dead — the bit can never hunt more than 6 mm down.
Runaway guard1.2 mm past known copperOnce a surface height is known, a point that descends much deeper without contact aborts as RUNAWAY (missed copper — a hole or a bad clip) instead of drilling into the bed.
Abort everywhere—! (the STOP button) is checked between every Z step and whenever a move stalls — including when opening the lid pauses the machine.
Hole test depth cap0.2 mm past the surfaceThe fiducial finder's touch tests can never plunge meaningfully into a hole.

Serial protocol (reference)

115200 baud, newline-terminated, all distances in microns. You rarely need this — the app speaks it for you — but it's handy for bench-testing with a serial terminal:

CommandMeaning
DSet datum: current X,Y and safe Z
P id x yProbe grid point at datum+(x,y); replies R id x y touchZ
BRe-touch the reference point (drift correction)
T / WTouch-off here / touch-off and zero the work-origin Z
H x yHole test: shallow touch at (x,y) — H 1 copper, H 0 hole (fiducial finder)
J x y / LJog to absolute XY (lifts first) / lift to safe Z
Q / G / VQuery position+touch / work origin / firmware version & features
C / M x y z sBegin an experimental streaming session / stream one move
!ABORT: stop, lift, halt — always honoured

Errors come back as E <id> <reason> — NOTOUCH, UNSTABLE, NODATUM, ABORT, RUNAWAY. See Troubleshooting for what each one means at the machine.

Experimental: streaming toolpaths over SPI

The Stream (exp.) button streams an operation's toolpaths move-by-move over the SPI link — no VPanel file player at all. It is deliberately hard to hurt yourself with:

  • Every session starts as a dry run: Z is held 2 mm above the origin, so nothing can cut.
  • A wet run additionally requires the spindle started by hand in VPanel and a confirmation prompt, and the raw speed value calibrated on dry runs first (the speed units are Roland-internal).
Experimental means experimental

For real jobs, export .nc and run it through VPanel. Streaming exists for research and for workflows VPanel can't do — treat it accordingly.
