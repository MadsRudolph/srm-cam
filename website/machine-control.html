Machine control

With the Arduino fitted, the bar along the bottom of SRM-CAM reads the machine's position, jogs Z, probes and zeroes it, runs the spindle, pauses, and stops. VPanel still plays the files and sets the spindle speed. The drawings are live: try the bar.

Windows only Firmware v3 Speed: VPanel's slider

Connect

Plug in the black USB (the Arduino; the white one is the mill, for VPanel). Pick the port on the bar, most likely Arduino first, and press Connect, or Machine › Connect / disconnect (Ctrl+L). Plugged in after SRM-CAM started? Machine › Rescan the serial ports. The chip on the left says what the link is doing: Machine offline, Connecting…, Linked, Lid open, Spindle on, or Link failed.

The machine bar

ControlDoes
X Y Z readoutThe machine's position, about three times a second, in machine coordinates. Z turns red and says Touch while the probe reads contact. SRM-CAM has no G54 switch: VPanel shows G54.
↓ ↑ + stepJog Z by the step: 0.01, 0.05, 0.1, 0.5 (the default), 1 or 5 mm. Page Down / Page Up do the same from anywhere, one step per press. Down is refused while the bit is touching; up always works.
Probe ZLower the bit from here until it touches, and stop on the copper. Tells SRM-CAM where the surface is (for the Z-reach check and the level page). VPanel's origin is untouched.
Zero ZTouch off the same way, then the firmware writes the machine's G54 Z origin at the copper and lifts 2 mm, like VPanel's Z under Set Origin Point. Only Z: X and Y are never moved. Check VPanel's G54 Z once before a job.
SpindleStart or stop the tool, at whatever speed VPanel's slider says: the machine ignores a speed sent over the link. Refused with the lid open.
PauseHold the machine where it is, spindle still turning; Resume carries on. VPanel's Pause, from SRM-CAM.
Click to jogClick the bed and the head lifts about 5 mm and travels there, snapping to the hole under the cursor. In the Bed — as cut frame only.
Run readoutWhile a run is being followed: how far it has got and the time left. Machine › Track this step's run, or leave Machine › Start tracking when the bit moves on.
STOPDrop the move in flight and stop the spindle. Esc does the same from anywhere, dialogs included. The bit stays where it is: raise it with Page Up.

Pause and STOP

They are different things. Pause holds the machine with the spindle turning, and Resume carries on from the same place. STOP drops the move and stops the spindle; the job does not resume, and the bit stays down in the cut until you raise it.

The Z readout is machine Z

Because the bar always shows machine Z, it is the quick way to check the Z travel after fitting a bit: with the bit on the copper, machine Z must stay above −50 mm, because −55 is the end of the travel. In VPanel you would switch the coordinates from G54 to Machine to see the same number (and back to G54 before zeroing).

What the link does not give you

Spindle speed is a VPanel setting

The machine ignores the rpm sent over the link: 500, 1000, 2000 and 3000 all settle on whatever VPanel's slider says. Set it there before any wet run.

  • Feed rate is not calibrated for streamed moves.
  • Only the lid bit of the status word is proven on this machine. The bit Roland labels "paused" does not mean paused here, so none of the others is shown as a machine state.
  • No X or Y zero. There is a control that zeroes Z and none that zeroes XY, on purpose: the screw fixture, dowel registration and every re-run depend on the XY origin staying put.

The spindle's rules

  • It will not start with the lid open.
  • The button follows the machine: a spindle started from VPanel shows as on here.
  • Disconnecting never stops a spindle SRM-CAM did not start.
  • A spindle SRM-CAM started stops by itself if the app goes quiet for ten seconds (the firmware's deadman; the bar's polling keeps it fed).
  • A dry run never spins the tool.
