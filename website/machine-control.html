Machine control

With the Arduino fitted to the SRM-20's SPI header, SRM-CAM drives the machine itself — spindle, pause, resume, stop, jog, probing and live position — instead of only writing files for VPanel.

Professional mode Firmware v3 VPanel still sets spindle speed

This page is the honest scoreboard. Every command below was tested on a real SRM-20 and the results are recorded in docs/2026-08-21-spi-command-audit.md. Where something does not work, it says so — a command that acknowledges is not a command that did anything.

What it does not give you

Spindle speed is still a VPanel setting

The machine ignores the RPM number. Commanding 500, 1000, 2000 and 3000 all settle on exactly the same speed — whatever VPanel's spindle slider is set to. SRM-CAM can start and stop the tool; it cannot choose how fast it turns. Set the speed on VPanel's slider before any wet run.

  • Feed rate is not calibrated. The link's speed value is Roland-internal, not mm/s. The default works out at about 19.1 mm/s; any other value has to be dialled in against a stopwatch.
  • Most status bits are unmapped. Only the lid bit is proven. The bit Roland labels "paused" demonstrably does not mean paused on this machine — it has been observed set on an idle, healthy mill, so do not read it as one.
  • There is no "run this program" command. Playing a whole job means streaming every move individually — see Streaming, which is still experimental.

The spindle, and the rules around it

A proven command can still do the wrong thing, so the button is fenced:

  • It will not start with the lid open — checked in the app, and again in the firmware.
  • It follows the machine, not the app. A spindle started from VPanel shows as on here.
  • Disconnecting never stops a spindle SRM-CAM did not start. The operator's own spindle is not the app's to police.
  • There is a deadman in firmware: a spindle SRM-CAM started stops by itself if the app goes quiet for 10 seconds.
  • A dry run never spins the tool at all.
Pausing a streamed run is safe to hold

The deadman counts host silence, and a hold would once have been silence — pause a wet run for more than ten seconds and the spindle stopped, then the run resumed into copper with a stationary tool. SRM-CAM now keeps talking to the board while it holds, and re-checks that the spindle is actually turning before resuming. If it is not, the run stops and lifts instead of cutting.

Streaming a job (experimental)

This is not the normal path

For real jobs, export .nc files and play them from VPanel. Streaming exists so the machine can eventually be driven end to end from SRM-CAM, but the speed units are not calibrated yet. Treat it as a bench feature.

Every session starts as a dry run — Z is held 2 mm above the work origin and nothing can cut. A wet run starts and stops the spindle itself, holds on Pause, and aborts if the lid opens — checked before the first move, then at least once a second and at least every ten moves, so a short job is covered too — but the spindle speed must still be set on VPanel's slider first, and the raw speed value has to be validated on dry runs.

Bed leveling is not applied to a streamed job

The height map warps exported files. A streamed job runs at nominal Z. If you have probed a map and need it honoured, export and run from VPanel.

Checking the link

  1. From the app Machine → Machine test… runs each command and reports PASS / FAIL / UNKNOWN with a pasteable report. Read-only by default; motion and spindle tests are armed separately. Treat a PASS on job control as "the opcode was accepted", not "the machine did it".
  2. From the command line python scripts/srm20_bench.py --port COM5 --features is the safe, read-only "is the board flashed and talking to the machine?" check. Add --map-bits, --frame-soak or --speed-sweep for the longer experiments.
In Novice mode

The machine dock and this whole menu are hidden, including STOP — and so is bed leveling, for exactly that reason: probing drives the machine, and a mode with no stop button has no business starting motion. Novice keeps Corner = tool, which only reads the tool position and commands nothing. Switch to Professional to drive the machine.
