Milling a board

The single-sided workflow, start to finish.

Load→ Place→ Check→ Export→ Run in VPanel

1. Load & configure

In 1 · Setup board: Load Gerber folder..., set a Name (= export file prefix).

  • Preset → Apply — a complete bit + feeds set for all three operations. Built-in: SRM-20 0.8 mm flat. Tweak, then Save... your own.
  • Stock — measure your board with calipers; nominal 1.6 mm varies.
  • Auto depth = stock + — drill/cutout depth = stock + breakthrough (default 0.1 mm). Leave on.

2. Place on the bed

  • Drag the design on the preview, or type Place X/Y. Rotate 90° as needed.
  • Show bed (fit check) confirms it fits.
  • Enter your copper piece under Copper stock — jog to its corner and hit Corner = tool, then Center design.

3. Check before cutting

  • Red channels on the Traces preview = gaps the bit can't isolate → will short. Fix in KiCad or use a smaller bit / V-bit.
  • Diagnostics — fits the bed? deepest cut inside the Z range? holes vs bit? Run it before full-bed jobs.
  • Simulate 3D — play back the whole cut.
  • Feed card (optional) — cut a feed ladder on scrap, photograph it, and the app recommends the fastest clean feed.

4. Export

<name>_airpass.nc           DRY RUN — spindle off, bit 5 mm up. RUN FIRST.
<name>_traces.nc            isolation (mirrored)
<name>_drill.nc             one bit, larger holes interpolated (default)
<name>_drill_<dia>mm.nc     one file per diameter (multi-bit mode)
<name>_cutout.nc            outline + tabs — run LAST
<name>_runplan.txt          READ FIRST: order, bits, zeroing

Machine = Roland SRM-20 (G-code) (default, recommended). RML available as fallback.

5. Run in VPanel

  1. Watch the dry run first Send <name>_airpass.nc before anything else. The spindle stays off, the bit is held 5 mm up, and it traces where the board will be cut, slowly enough to follow. If the bit leaves the copper, stop and re-place the stock — nothing has been cut. Worth doing before every job. See Holding the copper.
  2. Set the G54 origin XY zero once for the whole board. Re-zero Z only after every bit change.
  3. NC-code mode Cut → Add → Output — the .nc streams like RML.
  4. Run-plan order Airpass → traces → drill → cutout last. Re-zero Z at each bit change (Zero Z on machine does it electrically — hardware).
Z travel

~60 mm usable Z. If the surface sits too low the head tops out and cuts air/shallow. Fix: raise the work surface (add spoilboard). Diagnostics checks this.

Track the run

Machine connected → the Run: row follows the job: pick the operation, Auto starts tracking when the tool moves, progress bar + ETA count down, live crosshair on the preview (Trail draws the path).
