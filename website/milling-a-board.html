Milling a board

The complete single-sided workflow: load the design, place it on the bed, check it, export one file per operation, and run them in VPanel.

Load→ Place→ Check→ Export→ Run in VPanel

1. Load the design

In 1 · Setup board, click Load Gerber folder... and pick the folder with your KiCad plot output. SRM-CAM finds the copper layers, the Edge.Cuts outline, and the Excellon drill files automatically. Give the job a Name — it becomes the prefix of every exported file.

The three operations

Every board becomes three separate jobs, each exported as its own file and run with the right bit:

OperationSource layerWhat it does
TracesB.Cu (mirrored for bottom-up milling)Isolation milling: cuts channels around every copper feature. Multi-pass via offsets, or full copper clearing with offsets = -1.
DrillExcellonPlunge-drills every hole — one file per diameter, or a single-bit file (see below).
CutoutEdge.CutsCuts the board free, leaving holding tabs so it can't fly off at the end.

Switch the preview between them with the Traces / Drill / Cutout tabs. What you see in the preview is what exports.

2. Pick a preset and set the stock

The Preset dropdown applies a complete bit + feeds/speeds set across all three operations in one click. The built-in SRM-20 0.8 mm flat preset (applied on startup) runs everything with a single 0.8 mm flat endmill on ~1.6 mm stock. Apply a preset, tweak what you need, and Save... your own under a new name.

Then tell the app about your material:

  • Stock thickness — measure your actual copper-clad with calipers; nominal 1.6 mm boards vary.
  • Auto depth = stock + — with this checked (default), drill and cut-out depth is automatically stock thickness plus a small breakthrough (default 0.1 mm into the spoilboard). Uncheck to set depths manually in the job parameters.
V-bit engraving

The trace tool can be a flat endmill or a vbit engraver. For a V-bit you enter the tip diameter, included angle, and a target width; the plunge depth is back-solved so the cut is exactly that wide. The tool cross-section graphic in the panel shows what you've configured.

3. Place it on the bed

  • Drag the design directly on the preview (Move on bed (drag) is on by default), or type exact coordinates in the Place X/Y spinboxes.
  • Rotate 90° turns the board in quarter steps.
  • Show bed (fit check) draws the SRM-20 bed outline so you can see the board actually fits.
  • Measure (ruler) gives you an on-canvas ruler for checking distances.

Tell it where your copper is

The Copper stock group lets you enter the real piece of copper-clad on the bed — its Size (W×H) and Corner position. With the machine connected, jog the tool to the stock's corner and click Corner = tool to capture it exactly, then Center design to put the board in the middle of the material. Show copper stock draws the piece on the preview so you can see the margins.

4. Check before you cut

Isolation preflight

On the Traces preview, any copper gap narrower than the bit shows in red with a status-bar warning. These are channels the bit physically cannot isolate — potential shorts. Fix them in KiCad (widen clearance), use a smaller bit or a V-bit, or accept them knowingly.

Diagnostics

The Diagnostics button runs the pre-flight checks in one go: does the job fit the bed, does the deepest cut fit the SRM-20's Z travel (probe Z first so it knows where the surface is), and hole sizes versus the drill bit. Run it before any full-bed job.

3D simulation

Simulate 3D opens the toolpath simulator: orbit with the mouse, scrub or play back the whole cut, and watch the stock being removed. You can also simulate any exported file with Open & simulate file... — useful for double-checking a file you're about to hand to VPanel.

Dial in the feed on scrap (optional)

The Feed card button exports a feed-ladder test card — one engraved block per feed rate, with the value engraved next to it. Cut it on scrap, photograph it, and feed the photo back in (Score card photo…): the app scores every block and recommends the fastest feed that still cuts clean.

5. Export

Export toolpaths... writes one file per operation into your chosen folder (defaults to Documents\SRM-CAM\exports):

<name>_bottom_traces.nc     isolation (mirrored for single-sided)
<name>_drill_0.8mm.nc       one per hole diameter (or one single-bit file)
<name>_cutout.nc            outline with holding tabs
<name>_runplan.txt          read this first — the run order, bits, and zeroing steps

G-code or RML?

The Machine dropdown defaults to Roland SRM-20 (G-code), which writes .nc files with real-mm coordinates against the standard G54 work origin — this is the recommended path. Pick Roland SRM-20 for legacy RML output instead.

Drilling modes

  • Per-diameter (default): one file per hole size, smallest first, each plunge-drilled with a matching bit.
  • Single bit (checkbox in the drill parameters): one file, one small end mill. Matching holes are plunged; larger holes are interpolated — the tool circles out to size. Holes smaller than the bit are plunged at bit size and flagged in the status bar.

Full copper clearing (rubout)

Set the traces offsets parameter to -1 to clear all background copper — concentric pocketing clipped to the outline, the equivalent of a laser rubout. Much slower (many passes), but leaves no stray copper.

6. Run it in VPanel

  1. Set the work origin In VPanel, jog to your origin and set the G54 user origin. Follow the run plan: set XY zero once for the whole board, and re-zero Z only after every bit change.
  2. Switch VPanel to NC-code mode The .nc files stream exactly like RML: Cut → Add → Output. Coordinates reference the G54 origin; the file header clears any stale tool-length offset automatically.
  3. Run in run-plan order Traces → drill (smallest bit first) → cut-out last (the board is only held by tabs after it).
  4. Change bits carefully After each bit change: re-zero Z on the copper surface (never XY). The Zero Z on machine button can do the touch electrically if the red probe clip is on the copper — see Hardware & firmware.
Watch the Z travel

The SRM-20 has roughly 60 mm of usable Z range. If the work surface sits too low, the tool can't reach cutting depth — the symptom is the head lifting to the top and cutting air or cutting shallow. If Diagnostics warns about Z range, raise the work surface (add spoilboard) rather than lowering the origin. See Troubleshooting.

7. Track the run live

With the machine link connected (see Hardware & firmware), the Run: row at the bottom follows the job as VPanel plays it:

  • Pick the operation being run (Traces / Drill / Cut-out).
  • With Auto checked (default), tracking starts by itself when the tool starts moving; otherwise press Track run.
  • The progress bar follows the tool through the toolpath and the ETA counts down the remaining cut time.
  • The live crosshair on the preview shows exactly where the bit is; enable Trail to draw where it has been.
