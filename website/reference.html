Files & reference

Everything SRM-CAM reads and writes, plus presets, CLI, and mouse shortcuts.

Input files

TypeFilesNotes
Gerber.gbr (+ .gbrjob)Standard KiCad plot output. B.Cu + Edge.Cuts minimum; F.Cu for double-sided.
Excellon drill.drl / .txtFrom KiCad's Generate Drill Files.
Session.jsonWhole app state, written by Save setup...
Height map.csvX, Y, dz — written by Save CSV on the leveling page.
Photo.png / .jpgBoard photo for the overlay and rework detection.

Output files

FileContents
<name>_runplan.txtRead this first. Run order, bit per step, spindle notes, zeroing instructions, pin sizes.
<name>_airpass.ncDry run. Spindle off, bit held 5 mm up, traces the outline. Step 0 of the run plan. Single-sided exports only.
<name>_traces.ncIsolation milling (mirrored). Leveled if Apply bed leveling on export is on. Named <name>_bottom_traces.nc on a double-sided job.
<name>_drill.ncAll holes with one bit, larger ones interpolated — the default.
<name>_drill_<dia>mm.ncOne file per hole diameter, smallest first. Multi-bit mode only (--multi-bit).
<name>_screws.nc + .txtScrew fixture: M4 clearance holes through the copper, plus the procedure. See Holding the copper.
<W>x<H>_bedfixture.nc + .txtBed fixture: three dowel-pin holes. Named after the stock size, not the board — the fixture is per-bed.
<name>_cutout.ncBoard outline with holding tabs. Run last.
<name>_align.ncDouble-sided only: dowel/fiducial holes.
<name>_top_traces.ncDouble-sided only: top isolation (fiducial mode: warped to the measured fit; optionally leveled).
<name>_<side>_<op>_rework.ncRework pass: toolpaths clipped to your boxes, each at its own depth.

Default output: G-code (.nc, mm, G54 origin, plain G0/G1). The Roland SRM-20 machine choice writes RML instead.

Workspace layout

Documents\SRM-CAM\
├── sessions\    saved setups (.json) — Save/Load setup
├── exports\     exported .nc / .rml jobs + runplan
└── photos\      board photos for the overlay

File dialogs remember the last folder you used per category. Power users can relocate the whole workspace with the SRM_CAM_HOME environment variable.

What a session contains

One .json from Save setup...: board (Gerber folder path), name, placement/rotation, machine, stock, all job parameters, double-sided config, leveling grid + probed Z, rework boxes, and the aligned photo (copied next to the session).

Moving a session to another PC?

Bring the Gerber folder too — the session references it by path. Everything else travels inside the file.

Presets

A preset is a complete bit + feeds/speeds set covering all three operations. Merge order, later overrides earlier by name:

  1. Built-in — ships with the app (SRM-20 0.8 mm flat opens applied).
  2. Team-shared — examples/presets.json in the install/repo.
  3. Personal — ~/.gerber2rml/presets.json, written by Save...

The calibration coupon

Load examples/calibration — a bundled 40×30 mm board with isolation pairs, drill sizes, a 10 mm registration grid, a roundness ring, and a tabbed cut-out. Cut one after changing bits, stock, or machine.

Command line

python -m gerber2rml                                          # GUI
python -m gerber2rml.cli <gerber-folder> -o <out> -n <name>   # headless export
python -m gerber2rml.doctor                                   # fix deps after git pull

Status chips

Six chips in the status bar light as your setup completes. Green means in place. They refresh on a timer rather than on every event, so a chip can lag a second or so behind the thing it reports:

ChipLit when
boarda Gerber folder is loaded (shows the board name)
meshthe height map has at least 3 points and bed leveling is ticked (shows the count)
fita fiducial fit has been computed (shows the RMS)
photo / boxesa photo overlay is aligned / rework boxes are marked
linkthe machine link is connected
