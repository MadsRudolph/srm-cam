Files & reference

Every file SRM-CAM reads and writes, the preset system, the calibration coupon, CLI usage, and the mouse interactions worth memorizing.

Input files

TypeFilesNotes
Gerber.gbr (+ .gbrjob)Standard KiCad plot output. B.Cu + Edge.Cuts minimum; F.Cu for double-sided.
Excellon drill.drl / .txtFrom KiCad's Generate Drill Files.
Session.jsonWhole app state, written by Save setup...
Height map.csvX, Y, dz — written by Save CSV on the leveling page.
Photo.png / .jpgBoard photo for the overlay and rework detection.

Output files

FileContents
<name>_runplan.txtRead this first. Run order, bit per step, spindle notes, zeroing instructions, pin sizes.
<name>_bottom_traces.ncIsolation milling (mirrored). Leveled if Apply bed leveling on export is on.
<name>_drill_<dia>mm.ncOne per hole diameter (smallest first), or one single-bit file with interpolated large holes.
<name>_cutout.ncBoard outline with holding tabs. Run last.
<name>_align.ncDouble-sided only: dowel/fiducial holes.
<name>_top_traces.ncDouble-sided only: top isolation (fiducial mode: warped to the measured fit; optionally leveled).
<name>_<side>_<op>_rework.ncRework pass: toolpaths clipped to your boxes, each at its own depth.

All exports default to G-code (.nc, real millimetres, G54 origin, pre-linearised G0/G1 — no arcs or canned cycles). Choosing the Roland SRM-20 machine instead writes RML (.rml).

Workspace layout

Documents\SRM-CAM\
├── sessions\    saved setups (.json) — Save/Load setup
├── exports\     exported .nc / .rml jobs + runplan
└── photos\      board photos for the overlay

File dialogs remember the last folder you used per category. Power users can relocate the whole workspace with the SRM_CAM_HOME environment variable.

What a session contains

One .json from Save setup... restores everything:

  • the loaded board (Gerber folder path) and job name,
  • placement, rotation, machine choice, stock dimensions,
  • all traces / drill / cutout parameters,
  • double-sided configuration (method, pins, fiducials, flip direction),
  • the bed-leveling grid and probed Z values,
  • rework boxes with per-box depths and lvl flags,
  • the aligned photo (copied next to the session, with its anchors).
Sessions reference the Gerber folder by path

If you move a session to another PC, bring the Gerber folder too (or fix the path when loading). Everything else — mesh, boxes, photo — travels inside the session.

Presets

A preset is a complete bit + feeds/speeds set covering all three operations. Merge order, later overrides earlier by name:

  1. Built-in — ships with the app (SRM-20 0.8 mm flat opens applied).
  2. Team-shared — examples/presets.json in the install/repo.
  3. Personal — ~/.gerber2rml/presets.json, written by Save...

The calibration coupon

A bundled 40×30 mm test board that exercises every operation — load examples/calibration as the Gerber folder, no KiCad needed. It contains isolation pairs at 0.8 mm clearance, a drill-size row, a 10 mm registration grid (measure with calipers), a 6 mm roundness ring, and a tabbed cut-out. Cut one whenever you change bits, stock, or machine — it tells you in one small board whether your setup is dialed.

Command line

python -m gerber2rml                                          # GUI
python -m gerber2rml.cli <gerber-folder> -o <out> -n <name>   # headless export
python -m gerber2rml.doctor                                   # fix deps after git pull

The CLI exports the same traces/drill/cutout files as the GUI with default settings — handy for batch work. --gcode / RML selection matches the GUI's Machine dropdown.

Status chips

The status-bar chips light as your setup completes. Green means in place:

ChipLit when
boarda Gerber folder is loaded
placedthe board has been positioned on the bed
grid / mesha probe grid is built / the height map is probed or loaded (with point count)
photo / boxesa photo overlay is aligned / rework boxes are marked
machine / touchthe serial link is connected (shows the port) / the touch probe reads
fita fiducial fit has been computed (shows the RMS)
